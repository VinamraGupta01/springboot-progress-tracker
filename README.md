# 🚀 Overview

ProgressTracker is a backend-driven productivity management application designed to help users create goals, track progress, and monitor overall performance through a centralized dashboard.

The project follows a layered Spring Boot architecture and demonstrates real-world backend development practices including:

- REST API Design
- Service Layer Architecture
- Database Integration
- Exception Handling
- Repository Pattern
- Clean Code Principles

---

# 🏗️ Project Architecture

```text
src/main/java/com/vinamra/progresstracker

├── controller
│   ├── DashboardController
│   ├── GoalController
│   └── ProgressController
│
├── entity
│   ├── GoalEntity
│   ├── GoalStatus
│   └── ProgressEntity
│
├── repository
│   ├── GoalRepository
│   └── ProgressRepository
│
├── service
│   ├── DashboardService
│   ├── GoalService
│   └── ProgressService
│
├── exception
│   └── GlobalExceptionHandler
│
└── ProgressTrackerApplication
```
